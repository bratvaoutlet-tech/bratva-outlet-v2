# Bratva Outlet V2

E-commerce exclusivo Bratva Outlet - TanStack Start + React 19 + Supabase

## Features

- ✅ Homepage com hero + categorias
- ✅ Catálogo de produtos com filtros
- ✅ Carrinho persistente
- ✅ Checkout com endereço
- ✅ Autenticação
- ✅ Admin dashboard
- ✅ Gerenciar produtos

## Stack

- React 19
- TanStack Start + Router
- Supabase (PostgreSQL)
- Tailwind CSS
- Radix UI
- Zustand (cart)
- TypeScript

## Quick Start

```bash
git clone https://github.com/bratvaoutlet-tech/bratva-outlet-v2.git
cd bratva-outlet-v2
npm install
cp .env.example .env
# Preenche .env
npm run dev
```

Acessa http://localhost:5173

## Deploy (Vercel)

```bash
git push origin main
```

Vercel detecta automaticamente e faz deploy!
